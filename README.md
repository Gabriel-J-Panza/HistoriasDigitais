# Crônicas de Aurelia

Este repositório guarda o site **Crônicas de Aurelia**, um blog de fantasia baseado no universo de Aurelia. O mapa funciona como um livro: cada cidade abre uma página com personagens, aliados e capítulos das histórias em uma versão mais completa do que os resumos publicados em outros formatos.

Você não precisa entender de programação para acompanhar o projeto. O endereço publicado é:

<https://gabriel-j-panza.github.io/HistoriasDigitais/>

## Como acompanhar novidades

O GitHub é o lugar onde o site e suas atualizações ficam registrados. Para receber avisos quando uma nova versão for publicada:

1. Abra a página do repositório: <https://github.com/Gabriel-J-Panza/HistoriasDigitais>.
2. Clique no botão **Watch** (ou **Seguir**) no alto da página.
3. Escolha **Custom**.
4. Marque **Releases** e confirme.

Quando uma nova release for criada, o GitHub poderá enviar um e-mail conforme as notificações da sua conta. Para deixar de acompanhar, volte ao mesmo menu e escolha **Unwatch**.

Também existe o botão **Acompanhar no GitHub** dentro do site, que leva diretamente ao repositório.
